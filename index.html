학습 경로​

기초 (Beginner)​

OpenTelemetry를 처음 접하는 분들을 위한 기본 개념과 시작 가이드입니다.

  • OpenTelemetry 소개 - OTel이란 무엇인가?
  • 핵심 개념 - Trace, Span, Context 이해하기
  • 아키텍처 - OTel 구성 요소 이해
  • 시그널 - Traces, Metrics, Logs 상세
  • 시작하기 - 첫 번째 OTel 앱 만들기

중급 (Intermediate)​

OTel Collector와 백엔드 시스템을 연동하는 방법을 배웁니다.

  • OTel Collector - Collector 이해하기
  • Collector 설정 - 상세 설정 방법
  • Jaeger 연동 - Jaeger 백엔드 연결
  • Tempo 연동 - Grafana Tempo 연결
  • 계측 - 다양한 계측 방법
  • Context 전파 - 서비스 간 컨텍스트 전달

고급 (Advanced)​

프로덕션 환경에서 OTel을 운영하는 고급 기술을 다룹니다.

  • MSA 아키텍처 - 마이크로서비스 설계
  • 샘플링 전략 - 효율적인 샘플링
  • 프로덕션 배포 - 프로덕션 배포 가이드
  • 성능 최적화 - 성능 튜닝
  • 보안 - 보안 강화
  • 트러블슈팅 - 문제 해결

실습 (Practical)​

실제 코드와 함께 배우는 실습 가이드입니다.

  • Docker Compose 실습 - 전체 스택 구성
  • Kubernetes 배포 - K8s 환경 배포
  • Node.js 예제 - Node.js 상세 계측
  • Java 예제 - Java/Spring 계측
  • Python 예제 - Python/FastAPI 계측
  • Go 예제 - Go 계측

실제 사례 연구 (Case Studies) 🆕​

글로벌 기업들의 OpenTelemetry 도입 성과와 교훈입니다.

  • ROI 분석 및 도입 전략 - 비용 대비 효과와 전략적 접근

OpenTelemetry의 이점​

영역이점
개발통합된 API로 일관된 계측, 벤더 종속성 제거
운영분산 시스템 가시성, 빠른 문제 진단
비즈니스SLO 모니터링, 고객 경험 개선

빠른 시작​

# Docker로 빠른 시작
docker run -d --name jaeger \
  -p 16686:16686 \
  -p 4317:4317 \
  -p 4318:4318 \
  -e COLLECTOR_OTLP_ENABLED=true \
  jaegertracing/all-in-one:1.53

# Jaeger UI: http://localhost:16686
# OTLP gRPC: localhost:4317
# OTLP HTTP: localhost:4318
